# Cr. Stone — modpack

Modpack Minecraft 1.21.1 (NeoForge) inspiré de *Dr. Stone*, avec son launcher.

## Jouer

1. Télécharge **Cr. Stone Setup** dans la [dernière version](https://github.com/Lyrrio/crstone-pack/releases/latest) et installe-le.
2. Connecte-toi avec ton compte Microsoft (il faut posséder Minecraft Java).
3. Clique sur **JOUER** : le launcher installe Java, Minecraft, NeoForge et le modpack tout seul, puis le tient à jour.

Windows peut afficher « Windows a protégé votre ordinateur » au premier lancement de l'installateur, parce qu'il n'est pas signé :
clique sur **Informations complémentaires** puis **Exécuter quand même**.

## Contenu du dépôt

- `pack.json` : le manifeste lu par le launcher (version, liste des fichiers avec leur empreinte SHA-1, nouveautés).
- `hosted/` : les fichiers propres au pack (mod Cr. Stone, scripts KubeJS, configs, options par défaut).

Les autres mods ne sont pas redistribués ici : le launcher les télécharge depuis CurseForge et Modrinth.
